About this skill

This course is designed for complete beginners who want a practical, no-fluff introduction to Python. Across four hands-on sessions, you'll go from "What's a variable?" to writing small real-world scripts — including a command-line to-do list and a simple data analysis mini-project. Marco keeps things relaxed and answers questions as they come up rather than sticking rigidly to a script.

What you'll learn

  • Python syntax, variables, and data types
  • Loops, conditionals, and functions
  • Working with lists, dictionaries, and files
  • Building a simple command-line project from scratch
  • Where to go next — libraries worth exploring
